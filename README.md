# 🛍️ Vrinda Store Data Analysis Dashboard (Excel)

## 📌 Project Overview
This project focuses on analyzing Vrinda Store sales data using Microsoft Excel. An interactive dashboard helps present sales performance and business trends in a clear, visual format to support data-driven decision-making.

## 🎯 Project Objectives
- Analyze store sales and order data.
- Understand customer purchasing patterns.
- Identify sales trends and business performance.
- Present key metrics through an Excel dashboard.
- Generate insights to support business decisions.

## 🛠️ Tools & Technologies
- **Microsoft Excel**
- Pivot Tables
- Charts and Data Visualization
- Data Cleaning
- Interactive Dashboard and Slicers (if included in the workbook)

## 📊 Key Analysis Areas
- Sales and order performance
- Customer demographics and purchasing behavior
- Sales distribution across categories and channels
- Monthly sales trends
- Regional performance
